# comfyui-anima-trainer

ComfyUI custom nodes that train an Anima LoRA (either from **an `IMAGE` + caption** or from **a folder of images + `.txt` captions**) and return a ready-to-use `MODEL`, so a single workflow run covers **curate → train → generate**.

Complements `custom_nodes/comfyui-hydralora/` (which only loads already-trained adapters). Training runs inside the local Dragon Trainer **training daemon** — a separate detached process — so a CUDA OOM kills only the job, not ComfyUI.

### Install shapes & daemon client

- **Inside the repo** (`<dragon_trainer_root>/custom_nodes/comfyui-anima-trainer`) or **Standalone** (copied into a separate `ComfyUI/custom_nodes/`):
  `nodes.py::_resolve_daemon_client` always imports the bundled pure-stdlib `._vendor.scripts.daemon.client.DaemonClient` via relative import (regenerated by `python tasks.py vendor-sync`), avoiding top-level `sys.modules['scripts']` collisions in standalone ComfyUI installs.
- **Daemon discovery:** `discover_pidfile` checks the per-user `~/.anima/daemon.json` mirror, `$ANIMA_DAEMON_PIDFILE`, `$ANIMA_LORA_ROOT`, or the in-repo pidfile (following ephemeral fallback ports automatically), and falls back to `127.0.0.1:8765` (override with `$ANIMA_DAEMON_PORT`).

Either way, the **Dragon Trainer repo and its running daemon must exist on the same machine** — the node only submits preprocess + training jobs over localhost HTTP; the daemon (started with `python tasks.py daemon`, compatibility alias `make daemon`, from the repo root) runs preprocessing and training inside the repo's `.venv`. The ComfyUI process itself does not need to run inside that venv.

## Nodes

Both nodes appear under the `anima/training` category, lock the training method to `configs/gui-methods/tlora.toml` (T-LoRA + OrthoLoRA, no ReFT), layer sibling `node_defaults.toml` (`blocks_to_swap = 0`, `save_every_n_epochs = 999`, `checkpointing_epochs = 999`, `use_custom_down_autograd = false`) below explicit UI overrides, and save the finished adapter to `<ComfyUI>/models/loras/<save_as_or_timestamp>.safetensors`.

### Anima LoRA Trainer (`AnimaLoRATrainer`)

Required inputs:
- `anima_model` — base Anima DiT checkpoint from ComfyUI's `diffusion_models` folder (same list as `UNETLoader`). Used as the training base **and** reloaded afterwards to build the output `MODEL`.
- `image` — `IMAGE` batch to train on (written with the caption to a temp dir and preprocessed via `tasks.py preprocess-config`).
- `text` — `STRING` caption for the image(s).
- `save_as` — `STRING` output LoRA filename (without `.safetensors`), saved into ComfyUI's `loras` folder. Blank → auto-timestamped `anima_trainer_<YYYYMMDD_HHMMSS>`.
- `rank` — `INT` (default `16`, range `1..256`). LoRA rank (`network_dim`); `network_alpha` is tied to `rank`.
- `epochs` — `INT` (default `25`, range `1..10000`). Number of training epochs (`max_train_epochs`).
- `lr` — `FLOAT` (default `5e-5`, range `1e-7..1e-2`). Learning rate (`learning_rate`).
- `gpu` — hardware preset selector:
  - `8GB` → `[low_vram]` preset (`gradient_checkpointing = true`, `unsloth_offload_checkpointing = true`)
  - `16GB` / `high` → `[default]` preset (`blocks_to_swap = 0`, reinforced by `node_defaults.toml`)

Optional inputs:
- `mask` — `MASK` loss mask(s) (white = train on region, black = ignore; one mask per image or a single mask broadcast across the batch). Connecting it enables `masked_loss = true`.

Output:
- `model` (`MODEL`) — the chosen base checkpoint loaded after training and patched with the freshly trained LoRA (`strength = 1.0`), drop-in compatible with downstream samplers without a separate loader node.

### Anima LoRA Trainer (Folder) (`AnimaLoRATrainerFolder`)

Trains on a multi-image dataset directory inside ComfyUI's `input/` folder.

Required inputs:
- `anima_model` — base Anima DiT checkpoint from `diffusion_models`.
- `dataset_dir` — subfolder of `ComfyUI/input/` containing training images paired with same-stem `.txt` caption sidecars (read-only; bucket-resized and cached into a temp dir). Refresh the node to pick up newly added folders.
- `save_as` — `STRING` output LoRA filename (blank → auto-timestamped).
- `rank` — `INT` (default `16`).
- `epochs` — `INT` (default `25`).
- `lr` — `FLOAT` (default `5e-5`).
- `gpu` — hardware preset (`8GB` → `low_vram`, `16GB` / `high` → `default`, `blocks_to_swap = 0` in `node_defaults.toml`).

Optional inputs:
- `mask_dir` — subfolder of `ComfyUI/input/` holding `{stem}_mask.png` loss masks (white = keep) matched by stem, or `(none)` to disable masked loss.

Output:
- `model` (`MODEL`) — base checkpoint loaded and patched with the trained LoRA.

## Notes

- **No MODEL input by design.** Holding the base DiT resident in ComfyUI while also spawning a trainer on the same GPU is an easy OOM, so neither node takes a `MODEL` socket. Each loads the chosen checkpoint itself *after* training finishes.
- **Daemon required.** If the training daemon isn't running, the node raises an error (it does **not** auto-start it). Start it with `python tasks.py daemon` (compatibility alias: `make daemon`) from the repo root, then re-run.
- **Serial preprocess → train chain.** Each run submits a `tasks.py preprocess-config` command job with `chain_train` attached on the daemon's serial GPU queue, resolving VAE / Qwen3 paths through ComfyUI's `folder_paths` when available.
- **Memory** — the node calls `comfy.model_management.unload_all_models()` and empties the CUDA cache before submitting so the daemon job has full GPU headroom.
- **Temp staging** — single-image / resized caches stage under `<repo>/output/tmp_trainer/<timestamp>/` (or ComfyUI's temp dir when standalone). Prune periodically.
- **Plain LoRA output** — T-LoRA + OrthoLoRA collapses to standard `lora_up`/`lora_down` keys at save time, so the saved `.safetensors` works in any ComfyUI LoRA loader.

## Out of scope

- Arbitrary method / warm-start / multi-subset overrides — use the WebUI (`python tasks.py web`) or CLI (`python tasks.py lora-gui <variant>`) for full configuration control.
- Baking the trained LoRA into DiT weights as a standalone checkpoint (use `python tasks.py merge` / `scripts/merge_to_dit.py`).
