## 归档说明

- 本目录下的 `specs/` 与 `plans/` 均为已完成或已冻结的历史过程快照，仅供溯源设计初衷与阶段门禁。
- 新的探索提案应放入 `docs/proposal/`，稳定结论放入 `docs/findings/`，用户功能与方法说明分别放入 `docs/features/`、`docs/methods/` 或 `docs/experimental/`。
