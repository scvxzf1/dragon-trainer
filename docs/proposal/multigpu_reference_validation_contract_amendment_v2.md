## 2. C1–C4 判据（替换后全文，冻结）

### C1 数据对齐门（精确，无容差）

W=1/B=2 与 W=2/B=1 两条路径必须满足：

1. **同 slot 同 stem**：前 N 步（N ≥ 3）每个 slot 两侧取到同一 stem，全部相等；
2. **索引算术**：双卡每步消费的 item 索引严格满足 `k*W + rank`；
3. **无重复**：每个 rank 连续步的 item 序列**互不重复**（跨 epoch 重放不计）。

判定：三条全满足 = 通过；任一不满足 = 该轮 S-d **无有效测量**（记 `unverified`，不得判通过或失败）。

### C2 步级梯度等价（按元素 ULP，不用 rel L2 绝对值）

fp32 下 step0 的**全批梯度**（未归约/已归约两侧均可，但须同口径）的**唯一判据**是：

- **`max|ΔG| ≤ 4 ULP(max|G|)`**。

「逐位相同的张量计数」（本轮 `196/392`）是**观测项，不是判据**：这个"半数"是在看到实测
`196/392` 之后才写下的，属于"用观测反推阈值"，与本次修订要纠正的错误同源。
已于 2026-11-08 终审中降级为描述性观测，判据只保留 ULP 一条（ULP 与实测量级无关，不会被观测反推）。

**为什么不用 rel L2 定这个门**：rel L2 在"稠密微扰"下会被放大误导——每个元素只差约 2.5 ULP，
但 `‖ΔG‖₂/‖G‖₂` 可以到 `6e-05`（因为 ΔG 与 G **近正交**：模长几乎不变，逐元素已经变了）。
这与 `lora_up` 零初始化造成的"分母陷阱"**同源**：rel L2 的分母小或方向正交都会让它失去判别意义。
ULP 是机器精度锚点，与实测量级无关，**不会随观测结果被反推**。

### C3 权重漂移（参照实测噪声地板，不设拍脑袋常数）

`rel L2(S-d) ≤ fp16 同配置重复跑的噪声地板`，参照值取 t17 三次重跑：
**2.040e-04 / 3.225e-04 / 3.988e-04**（取其中**最大**者作界：`3.988e-04`）。

**必须写明的限制**：**不得**拿 fp32 同配置地板（5.634e-08）作参照。fp32 地板是"同一归约顺序
重复自己"的抖动，把它当界等于要求"两种**不同**归约顺序逐位相同"——正是 §1 论证的不可达条件。

### C4 恢复（S-g）两段

1. **续接逐位精确**：恢复臂与连续臂的 stem 逐步全等；`cursor` 与 `state` 文件 sha256 可核 —— **已通过**；
2. **权重散度**：20 步散度 ≤ 与 **C3 同一** fp16 噪声地板（`3.988e-04`）；
3. 报告须附**逐步散度曲线**、**首超 `1e-6` 的步号**、**epoch 边界有无台阶**。

原「第 20 步参数逐位相等」解除：同一台卡上 fp32 内核本身就不是逐位确定的（实测同配置重复
权重 rel L2 `5.634e-08`、梯度地板 `5.703e-07`，见 §5.1），要求跨归约顺序逐位相等在 v1 就不可达。

## 5. 支撑实测（本修订的证据基础，全部来自 t43 / t45，未新增运行）

### 5.1 fp32 同配置重复**并非逐位**

| 口径 | single batch2（A vs B） | dual batch1（A vs B） |
| --- | --- | --- |
| 权重 rel L2 | **5.634e-08** | **5.492e-08** |
| 权重 max_abs | 1.832e-06 | 1.446e-06 |
| 梯度层地板（同配置） | **5.703e-07** | **5.759e-07** |

梯度层 392 张量中 200 张逐位相同。⇒ V100 的 fp32 内核存在 **~5.5e-8 级非确定性**，但**远低于 `1e-6`**。
因此 v1 的 `1e-6` 超阈**不是**来自"普遍抖动"，而是来自**跳配置**（换归约顺序/形状）。

### 5.2 归约分解（差异来自哪里）

| 对照 | 实测 rel L2 |
| --- | --- |
| 2 步等时距（`singleGA2` vs `dual2`） | **1.179e-06** |
| 10 步等时距（`singleGA10` vs `dual10t`，隔离 all-reduce） | **7.344e-05**（= S-d `1.5055e-04` 的 **49%**） |
| 单步 S-d（权重） | **6.726e-06** |
| 10 步 S-d（权重） | **1.5055e-04** |

⇒ all-reduce 求均值单独产出 7.3e-05，**形状差贡献余下约一半**：**两者叠加**，不存在"唯一差异源"。
单步 S-d `6.726e-06` 只能称「**单步权重等价（符号层）**」（Adam 首步 `m̂/√v̂` ≈ sign，幅值被压掉），
**不得**写成"梯度等价"。

### 5.3 放大机制与指标学更正

- AdamW `m̂/(√v̂+eps)` 是**符号化归一**：`1e-07` 级差异被固化并按步积分（实测 10 步放大 **1393×**，
  几何均值 **2.24×/步**；lr `1e-4`）。这比"混沌"更具体，也解释了为什么 S-g 曲线是平滑倍增而非台阶。
- **`lora_up` 零初始化 ⇒ 分层 rel 无意义**：放大 = 分母小 **18.98×** × 误差大 **1.52×** = **28.9×**
  （组聚合口径）/ **41.4×**（逐层组内均值口径）。
- ⇒ **S-d 的严重性以 `max_abs 2.34e-04` 与 global rel L2 `1.5055e-04` 为准**，不看最差单层 rel。

### 5.4 t17 fp16 噪声地板（C3/C4 的参照集，v2 之前已存在）

`2.040e-04`（det-a vs det-b）/ `3.225e-04`（baseline vs det-a）/ `3.988e-04`（baseline vs det-b）。
**三者都比 S-d 的 `1.5055e-04` 大** ⇒ 在这个口径下，S-d 的漂移**小于同一张卡上"什么都不改、重跑一遍"的抖动**。

### 修订过程中被自己的实测证伪的两条预判（不删，留作教训）

1. 预期 step0 梯度张量 rel L2 在 `1e-8` 量级，**实测 `6.341e-05`**（只看模长相对差 `3.7e-09` 就外推张量级，

2. 预期 all-reduce 是唯一差异源，**实测只占 49%**（把"同形状输入"误当"同归约树"）。
