## 0. 采集环境与口径

| 项 | 值 |
| --- | --- |
| 数据集 | `image_dataset/style_8_4`（57 张 JPEG，295 MB） |
| 主机 | 36 逻辑核；`cjxl v0.12.0 a7a9c787 [_AVX2_,SSE4,SSE2]`；`djxl` 同版本 |
| 度量进程 | `/tmp/lvenv`（Python 3.14 + numpy 2.5.4 + scipy 1.18.1 + Pillow 13.0.0） |
| JPEG 编码/解码进程 | `/usr/bin/python3` + Pillow 13.0.0（libjpeg-turbo） |
| PSNR | 逐通道 `10*log10(255^2/MSE)`，报 RGB 三通道算术平均，并列出 R/G/B 分通道值 |
| SSIM | 高斯窗 sigma=1.5，逐通道计算后取 RGB 平均 |
| ΔE76 | CIE76 色差，sRGB→D65 XYZ→CIELab 逐像素计算；ΔE95 为其 95 分位 |
| 编码耗时 | JPEG 为同进程墙钟（含解码源图、不含解释器启动）；JXL 为 `cjxl` 子进程墙钟 |
| 解码耗时 | JXL 为 `djxl` 解码输出 PPM 子进程墙钟；JPEG 为 `Image.open`+`load`+`convert`+`tobytes` 同进程墙钟 |
| CPU% 与峰值 RSS | 子进程 `/proc/<pid>/status:VmHWM` 每 5~8 ms 采样 + `os.wait4` rusage |
| 采样策略 | 每档按体积升序等距抽取；1–5 MB 取 5 张、5–10 MB 取 5 张、10–15 MB 全取（仅 1 张） |

体积分布（全 57 张）：<1 MB 7 张、1–5 MB 16 张、5–10 MB 33 张、10–15 MB 1 张、>15 MB 0 张。
